## 领星 ASIN 产品表现表（2026-08-03 至 2026-08-09）

用户提供的 `产品表现ASIN（2026-08-03~2026-08-09，全部广告）` 文件含 1 个工作表、2,842 条数据行和 156 列。文件已确认是**连续 7 天的 ASIN 日粒度快照**：每天均为 406 个 ASIN、330 个父 ASIN，因而可为 7 天日销、30 天滚动补数、ASIN 库存和连续三天断货提供真实数据基础。

| 数据要素 | 领星实际字段 | 设计中的使用方式 |
|---|---|---|
| 日粒度 | `日期` | 新日快照主日期；现有解析器尚未映射，重构时必须新增映射与唯一键 |
| 产品层级 | `ASIN`、`父ASIN`、`MSKU`、`SKU`、`店铺`、`国家` | 库存按 `ASIN + 店铺 + 国家 + 日期` 保存；产品总览按 `父ASIN + 店铺 + 国家 + 周` 汇总 |
| 销量 | `销量`、`订单量`、`销售额`、`平均销量` | 变体销量看板和 7/30 天日销计算；连续 7 天共有 445 条正销量行 |
| 可售库存 | `FBA-可售`、`FBM可售`、`可用库存` | 规划可售库存以 FBA-可售为主，非 FBA 库存仅作为明细展示，避免双重计数 |
| 在途库存 | `FBA-在途`、`FBA-计划入库`、`AWD标发在途` | 规划总库存的在途层，仍需预计可售日才能进入时间预测 |
| 本地库存 | `本地可用` | 表内值只作为来源参考；库存规划改用用户在工作台手工维护的本地库存版本，保留审计历史 |
| 其他库存 | `AWD在库`、`AWD可用量`、`海外仓可用`、`采购量` | 单列展示与辅助核对，不与总库存简单相加 |

样本在 7 天内的 ASIN、父 ASIN 数量完全一致，说明文件适合作为日快照导入；其中 1,301 条记录的 `FBA-可售 + FBA-在途 + 本地可用` 大于 0。现有领星解析器已覆盖大部分业务列，但当前未映射 `日期`，且数据库使用周度字段保存导入周期，不能满足日粒度事实存储与 ASIN 库存追溯；这将作为后续迁移的核心改造点。

# 产品总览原界面回归标准

用户要求保留原产品总览的业务展示形式，仅切换底层数据源为领星 ASIN 日粒度数据的父 ASIN 周度汇总。

已核对截图的左侧和中部区域。页面应保留“产品运营总览”标题、系统/领星/赛狐数据源切换、在售总数摘要、搜索与站点/状态/店铺/运营/最近四周筛选栏，以及以父 ASIN 为一张可展开产品卡片的列表结构。卡片头部需要保留产品标题、父 ASIN、SKU、店铺、在售状态、国家标签、预警提示、生产库存与负责人等原有操作位置。

每张卡片展开后必须维持原始周度明细表格的阅读方式。数据行按自然周排列，并显示销量、订单、销售额、订单利润、Session、广告及转化指标等原页面列；日粒度数据只负责提供这些列的周度聚合值。不能以简化的四列摘要卡片替代原有的卡片展开和周度表格交互。

# 图片知识库统一受控采集迁移验证记录

## 结论

图片知识库的单ASIN、批量ASIN、Amazon美国站链接导入和局部刷新入口已切换至统一`Acquisition Job/Run`。这些入口不再创建“爬取中”图片集或调用旧`processImport`/`processPartialReCrawl`；Provider成功后先生成独立Source Snapshot与S3证据资产，人工逐图审核并确认后才投影到现有图片知识库表。

## 关键治理边界

| 项目 | 当前行为 |
|---|---|
| 新建导入 | 只创建受控采集Job；未确认数据不进入图片知识库 |
| 24小时缓存 | 复用Confirmed Snapshot，但仍执行消费者投影与Consumer Link |
| 局部刷新 | 只请求选定能力；主图/副图统一为完整图库能力 |
| 旧图保护 | 新快照确认前不删除旧图片；Provider未返回A+/品牌故事时不清空历史模块 |
| 手工上传 | 保持原有S3上传、人工标签和AI重分析路径，不经过Provider |
| 证据隔离 | 图片知识库仅保存已确认S3对象URI，不保存Provider原始URL为正式资产 |
| 费用与重试 | 单任务0.10美元上限；活动Job复用，已完成/失败/强制刷新可创建新尝试 |

## 验证结果

定向回归共18项通过，覆盖US链接解析、能力映射、字段状态局部替换、工作空间隔离、不可变确认链、路由加载与重试幂等。定向ESLint无错误，仅保留页面既有Hook依赖警告1项。生产构建、Bundle预算和图片知识库桌面截图通过。未执行新的外部采集，未执行青岛0198迁移或生产发布。

## 后续边界

旧内嵌爬虫辅助函数仍保留为不可达历史代码，等待其他消费者迁移完成后在全局退役阶段统一删除。图片知识库四类业务入口没有旧爬虫自动降级路径。

## 发布后页面可达性与密钥非回显验证

使用已登录的超级管理员会话访问`https://kuahaixing.com/settings`，页面成功加载“API连接管理”页。三类连接均可见，但仅显示脱敏连接状态、字段状态来源、密钥版本与最后替换时间；所有可编辑字段均是空白`password`输入框，未展示、掩码回填、导出或推断任何历史密钥。Apify卡片提供“无费用轻量校验”按钮，领星与赛狐的各自门禁说明正常显示；本次页面验证未填写字段、未点击保存/校验/重加密，也未产生Provider费用。

随后，已登录超级管理员会话触发了Apify“无费用轻量校验”。该动作仅允许账户身份端点检查，设计上不运行Actor、不创建资格Run或业务采集。截至本记录更新时，页面仍显示校验进行中，尚未出现成功或失败终态；因此不将Apify记录为已校验，也不启动任何付费资格任务。

## Apify轻量校验超时诊断与本地补丁

页面轻量校验最终返回固定脱敏类别`timeout`。在青岛服务器上执行的无令牌只读网络诊断证明`api.apify.com`可通过IPv4解析和HTTPS访问；账户端点在未携带认证的情况下约1.2秒返回预期HTTP 401。因此，网络不可达不是根因，且该诊断不读取配置、令牌或业务数据。

本地补丁将账户检查从全局`fetch`改为受控`node:https`请求：固定`family: 4`、10秒超时、`Authorization: Bearer`请求头认证、URL不含令牌，并在非2xx或超时时保持固定失败关闭。10项受控API连接定向测试、定向TypeScript/ESLint及生产构建/Bundle预算均通过。补丁尚未发布青岛；发布后必须重新执行无费用轻量校验，通过前不得创建两项Provider资格Run。

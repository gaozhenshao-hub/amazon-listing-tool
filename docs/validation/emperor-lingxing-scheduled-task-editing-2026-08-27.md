# 皇帝领星系统任务运营级编辑验收记录

**日期：**2026-08-27  
**范围：**工作空间1的ASIN日表现、FBA库存快照、广告关键词历史和父ASIN周汇总四项领星系统任务。

## 编辑边界

皇帝“定时任务”页面新增“编辑”抽屉。管理员可编辑任务显示名称、6段UTC Cron、启停、自动应用开关和异常跃升阈值。Cron秒字段固定为`0`；异常倍数限定为2–20，绝对增量限定为100–10,000。

父ASIN周汇总仍为`draft_only`：服务端和界面均锁定其自动应用开关。任务UID、数据域、MCP工具白名单、美国店铺范围、运行审计、库存货期/MOQ/成本和广告预算/竞价/否词/状态/结构均不可编辑。

## 单一触发器与审计

保存编辑时，系统只按现存`externalTaskUid`更新同一个Heartbeat任务的Cron、启停与描述；同时更新关联的`ops_lingxing_sync_schedules`执行配置和皇帝任务实体。不会创建第二个Cron，也不会改变MCP读取路径。管理员编辑会记录`emperor.scheduled_task.update`治理审计，包含数据域、自动应用状态、阈值和关联任务UID。

执行器从皇帝任务的`inputTemplate.anomalyThreshold`读取阈值，分别应用于ASIN日表现、库存和关键词的前日异常跃升校验。字段覆盖、分页截断、身份、字段有效性等既有阻断不受阈值编辑影响。

## 验证结果

定向Vitest共36项通过，覆盖皇帝系统任务展示与控制、计划映射、日/库存/关键词自动应用、异常阈值收紧、周汇总自动应用锁定和领星同步页的唯一管理入口。涉及路由、执行器、页面和契约测试的ESLint无错误。

完整TypeScript编译在当前沙箱中此前因资源限制终止，未返回类型诊断；本轮改动已通过运行时定向回归与静态检查。首次由管理员实际保存编辑时，应只读复核对应Heartbeat UID、计划Cron、皇帝任务审计记录和后续Run/Trace连续性。

# 皇帝对话任务运行详情入口：视觉回归记录

## 验证范围

本次本地工作台回归覆盖`/emperor/conversations`与`/emperor/trace`。对话管理器保持既有三栏结构：左侧为会话列表，中部为消息、附件和受控知识上下文，右侧为可编辑执行计划。未发现空白页、布局溢出或导航中断。

运行历史页能够加载既有Skill调用记录及详情空状态。已为已完成的对话Skill步骤加入“运行详情”入口，目标路径携带对应`runId`，运行历史页会在当前页包含该Run时自动选中它。生产构建后仍需使用最新的低风险验收Skill Run进行一次直达打开确认。

## 治理边界

该入口仅导航至现有只读运行详情，不会重新执行Skill、Agent、Tool或MCP，也不暴露附件原件、对象存储密钥或模型凭据。对话步骤的Run Ledger Trace仍由服务端创建并写入脱敏Context Manifest。

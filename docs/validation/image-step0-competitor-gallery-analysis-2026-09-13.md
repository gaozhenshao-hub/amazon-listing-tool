# 智能图片建议 Step 0：主要竞品全图分析验证记录

## 实现结论

Step 0现已形成并行双轨：`竞品全图分析`按单个竞争对手纵向分析整套已确认图片，`卖点表达方式`保留原有横向分组与总结功能。两条轨道互不覆盖。

## 数据与治理

| 项目 | 当前实现 |
|---|---|
| Research Subject | 绑定项目、工作空间和已确认Acquisition Snapshot；每项目最多一个主要竞争对手 |
| 图片证据 | 仅使用Snapshot中已确认且具备S3 Key/内容哈希的资产；视觉模型只接收短期签名URL |
| 逐图事实 | 图片目的、类型、卖点、表达方式、构图、视觉风格、文案策略、证明方式、受众、情绪、优势、风险、摘要、置信度 |
| 整套总结 | 定位、受众、叙事顺序、视觉系统、卖点架构、优势、薄弱点、风险、可借鉴原则、不可照搬模式、差异化机会 |
| 证据门禁 | 每条策略结论必须引用该竞品已确认assetId；跨竞品或未确认资产引用失败关闭 |
| 人工决策 | 逐图事实和整套总结均可编辑；确认后生成不可变`competitor_gallery` Step 0 Artifact |
| Step 0门禁 | 无Research Subject时兼容原流程；存在Research Subject时必须有唯一且已确认的主要竞品全图分析 |

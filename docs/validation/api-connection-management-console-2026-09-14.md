# 受控第三方 API 连接管理后台验证记录

**日期：** 2026-09-14  
**环境：** 开发环境，系统设置 `/settings`  
**范围：** Apify、领星、赛狐受控连接管理后台；不填写、不读取、不导出任何真实密钥。

## 视觉与权限状态

冷启动后，系统设置默认打开“API连接管理”页。超级管理员会话下可见三类连接卡片及以下安全信息：连接用途、就绪状态、字段级“已配置/未配置”来源、密钥版本（如存在）和最后轻量校验的脱敏状态。Apify卡片在兼容环境变量存在时仅显示“兼容环境配置：兼容来源”；页面未展示令牌值、掩码原值、长度或前缀。

每个字段均是空白的密码输入框。已配置状态的提示为“留空则保留当前密钥；重新输入即可替换”，并在视觉检查中确认未发生历史密钥回填。操作按钮为“保存/替换密钥”“无费用轻量校验”“重加密密文”；赛狐显示待官方受限API合同的失败关闭提示。

# 单ASIN广告关键词归因修复验收（2026-08-27）

## 问题与证据

用户在产品总览的父ASIN `B0H1Q46PVH`（3店-US）详情页看到“暂无广告关键词数据”。初步的工作空间1统计遗漏了历史映射中的空工作空间记录，不能作为归因不存在的结论。按系统的工作空间兼容规则复核后，该父ASIN存在4条映射记录，其中“6099筐子”和“洗碗机框子”均对应3店-US；另有重复的历史空工作空间版本和当前工作空间版本。

根因是关键词查询仅以`ad_keyword_weekly.parent_asin`或`product_id`筛选，未在查询时并入已确认的“广告组合→父ASIN”映射。历史广告关键词事实仍保留空`parent_asin`，因而详情页错误显示空态。没有将任意店铺或任意广告组合强行归因给产品。

## 修复与边界

`adTracking.getProductKeywords`现以三种可验证条件的并集读取：直接`product_id`归因、直接`parent_asin`归因，以及当前工作空间兼容的广告组合映射。映射条件始终同时匹配广告组合名称；映射含店铺时还必须匹配店铺名称。关键词元数据也改按父ASIN隔离，避免导入模式读取无关元数据。

| 验收项 | 结果 |
| --- | --- |
| 截图目标父ASIN | `B0H1Q46PVH`，3店-US |
| 修复后关键词 | 25个关键词、6周数据 |
| 归因来源 | 已确认组合“6099筐子”“洗碗机框子”及店铺3店-US |
| 不可归属记录 | 保持不展示，不做名称模糊匹配 |
| 回归 | `adDownstreamLinkage.contract.test.ts` 3项通过；`adTracking.ts` ESLint通过 |

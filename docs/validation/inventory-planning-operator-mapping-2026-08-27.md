# 库存规划负责人映射修复验收（2026-08-27）

## 根因

库存规划查询使用最新日快照直接输出`latest.operator`。领星MCP日快照的负责人字段并非每条都有值，而产品总览已存在的产品主档及历史周度负责人映射没有被库存规划复用，造成页面在最新日快照基准日上大面积显示“未映射”。这不是负责人数据被删除，也不是跨店匹配失败。

## 修复规则

库存规划按以下顺序确定负责人：最新子ASIN日快照的直接负责人；同父ASIN和同店铺的产品主档负责人；同父ASIN、同店铺、同国家的历史周度负责人；否则保留“未映射”。最后再使用已确认的负责人名称映射完成标准化。该顺序不按子ASIN名称、品名或跨店记录做模糊匹配。

库存规划的负责人字段仅为归属与筛选用途；本次修复不更新库存、成本、货期、MOQ、缓冲或补货建议。

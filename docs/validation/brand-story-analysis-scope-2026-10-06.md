**日期**：2026-10-06

**状态**：本地实现、测试和生产构建已完成；**尚未执行数据库迁移或发布青岛**。

## 业务结果

| 业务情形 | 新行为 |
| --- | --- |
| 竞品采集 | 主图、副图、A+ 和品牌故事都可继续安全保存到竞品图库；不会删除或重新爬取现有图片。 |
| 初始分析范围 | 默认选择主图、副图及 A+，默认不选择 `brand_story`。 |
| 人工控制 | 操作人员可逐张勾选、按默认范围选择、全选已保存图片或清空；必须先保存并确认范围。 |
| AI 全图分析 | Job 必须绑定已确认的范围版本与哈希；只读入范围内资产。范围变更或替代时，运行前/写入前均失败关闭。 |
| 逐图事实 | 已存在、内容哈希未变化的范围内事实可复用；新增选中图片才会请求逐图 Skill。范围外图片不再触发该次分析。 |
| 表达方式联动 | 只返回当前确认范围内、且已确认逐图事实的图片；未选品牌故事不能进入卖点表达方式分析。 |
| 历史结果 | 历史分析和图片继续保留；首次确认新范围会使旧全图分析、表达选择/分析及综合 Artifact 失效，避免新旧证据混用。 |

## 数据与提示词合同

新增 `image_competitor_gallery_selection_versions`，每个范围版本持久化：项目与竞品对象、确认快照、版本号、筛选状态、已选资产 ID、范围哈希、创建/确认人及时间。`image_competitor_gallery_analysis_versions` 增加可空 `selectionVersionId`，因此历史分析保持兼容，不会被批量改写。

`image.step0.competitor.gallery.summary` 的生产迁移 Prompt 更新为：模型只能总结确认范围内的证据；没有纳入的 A+、品牌故事或普通图库不得被解释为“缺失”“未提供”或“不存在”；竞品图不得作为我方素材。

## 代码审查

### Stage 1：功能正确性

- **编译**：改动文件零诊断；全局 TypeScript 因 143 项历史诊断无法达成零错误，不阻塞本改动的定向验证。
- **运行/流程**：本地开发服务已重新加载；范围选择、保存、确认、分析启动合同、范围变更失效及表达候选过滤均由定向测试和生产构建覆盖。
- **数据持久化**：范围版本 → 选择哈希 → 分析版本关联为显式持久化链；重复保存相同范围复用版本，范围变更创建新版本。
- **UI**：范围卡与图片卡使用既有 shadcn/Tailwind 风格；提供默认、全选、清空、草稿、确认、禁用和范围外提示。

### Stage 2：代码质量

- **架构**：范围合同、仓储、服务、Job 和 UI 分层，未引入客户端外部数据读取。
- **安全**：服务端 Zod/合同验证拒绝空、重复和跨竞品资产；范围外资产不传模型、不进表达候选；无凭据或图片对象键进入前端。
- **性能**：逐图事实以内容哈希复用，避免范围调整后重复模型调用；当前竞品数量通常较小，现有图库读取仍按竞品对象加载，后续多竞品扩容时可再合并批量查询。
- **可访问性**：每张图片的选择框带可见文字与 `aria-label`，禁用态和键盘焦点沿用 shadcn 组件。

**审查结论**：未发现新增高优先级问题。可进入用户单独确认的迁移与青岛发布阶段；发布后不自动重新分析任何历史竞品图库。

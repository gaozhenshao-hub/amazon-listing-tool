# 领星异常数据复核模块验证记录

## 会话上下文初检

2026-08-27 在浏览器会话中读取 `auth.me`，确认当前用户为工作空间1的 `super_admin`，`defaultWorkspaceId = 1`。因此，异常复核队列在页面中显示为空并非由未登录或工作空间缺失导致；后续需继续核验前端请求与服务端结果的一致性。

随后以同一浏览器会话直接调用 `lingxingSync.listBackfillReviewQueue`，接口成功返回20个按日期归并的异常记录。页面空队列的原因为首次渲染时，队列查询与受QPS限制的领星目录查询被同批发起，局部失败响应使纯数据库结果未进入前端缓存。需以“目录查询已实际成功或失败结束”为条件延后历史和复核查询。

在采用目录状态门控后，接口仍可从同一已登录浏览器会话返回20条真实记录，但页面缓存仍显示0条。这表明需进一步将纯数据库复核队列从页面首屏的批处理查询中隔离，且应在未成功获得数据时展示错误或加载反馈，而不能误表示为“没有异常日期”。

再次以刷新后的页面复现：异常复核卡片和历史批次列表均显示0条，但同一认证会话的单接口读取正常。因此，问题已收敛为页面查询客户端的批处理/缓存行为，而非数据库、权限或复核队列的服务端筛选。

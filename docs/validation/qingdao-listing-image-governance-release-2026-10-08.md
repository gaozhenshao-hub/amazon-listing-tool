## 3. 运行时依赖修复与预演

发布过程中发现旧生产运行时没有完整的依赖树，`sharp` 等模块无法作为新受控上传路径的运行时基础。因此没有直接覆盖现网依赖，而是：

1. 在应用目录外建立候选运行时；
2. 用冻结锁文件安装完整依赖并验证 `vite` 与 `sharp` 可加载；
3. 在与现网等价的环境键名下，以 `AUTH_MODE=local` 在独立端口启动候选 Web；
4. 验证候选首页和 `/login` 均为 HTTP 200；
5. 再将已验证的候选工件原子接入应用目录。

候选日志中的 `OAUTH_SERVER_URL` 初始化提示并未阻断服务启动。青岛现有应用已确认支持**独立账号密码登录**；本次公网验收也直接呈现了该登录表单。

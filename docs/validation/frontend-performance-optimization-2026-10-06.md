# 前端性能 P0–P4 优化与青岛发布验证

**日期：** 2026-10-06  
**范围：** 青岛独立站 `kuahaixing.com` 的前端交付路径、可观测性、图片渲染、富文本分包与优雅停止。  
**边界：** 不执行采集、不调用 Provider 或 AI、不创建业务任务、不改变业务数据。

## 已实施能力

| 优先级 | 优化项 | 实现结果 |
|---|---|---|
| P0 | 静态资源交付 | Nginx 直接服务 `/assets/`；仅内容哈希资源设置一年 `immutable` 缓存；开启 gzip 协商；旧哈希资源保持真实 404，供客户端一次性恢复机制判断。应用路由继续交由 Node 服务返回 HTML，保持 `no-store`。 |
| P1 | 性能可观测性 | 新增受登录保护的 `performance.recordVitals`。浏览器仅对抽样会话发送 LCP、INP、CLS、TTFB、FCP 的脱敏、归一化路由和发布标识；每用户/工作空间每分钟限流。指标按工作空间隔离汇总，皇帝观测页可查看分位结果。 |
| P2 | 图片渲染 | 知识库预览及竞品/表达/参考/风格图库的非首屏图片使用延迟加载与异步解码；知识库首张缩略图保留优先加载；现有虚拟瀑布流保持不变。 |
| P3 | 首屏依赖 | 富文本聊天改为按需加载；Vite 将富文本、图表和图形依赖拆分，避免把低频编辑/图表能力纳入首屏必需资源。 |
| P4 | 恢复与稳定性 | 响应加入安全的 `Server-Timing` 和请求标识；运行时支持排空状态与优雅停止；网络状态横幅、错误边界可恢复操作和可复制的前端事件编号帮助用户自助恢复和定位问题。 |

## 青岛发布证据

- Nginx 配置在语法校验通过后 reload；原站点配置和性能片段均保留时间戳备份。
- 发布包在本地做敏感字面量与禁止文件扫描，通过后生成归档和逐文件 SHA-256 清单。
- 初次暂存校验因不同机器的默认排序差异**安全终止**，没有切换生产。改用固定字节序清单重新校验成功后才执行原子目录切换。
- Web、Worker、Scheduler 均已重启并为 `active`；Web 健康端点返回 `draining: false`。
- 生产 `dist/index.js` 与本地候选包哈希一致；旧版本目录已保存为可回滚备份。

## 发布后只读验证

| 检查 | 结果 |
|---|---|
| 内容哈希 JS/CSS | `200`、`Cache-Control: public, max-age=31536000, immutable`、`Content-Encoding: gzip`、`Vary: Accept-Encoding` |
| 应用路由 | `200`，HTML 保持 `no-store`，并返回请求标识和 `Server-Timing` |
| 旧资源 | 不存在的旧哈希资源返回 `404`，不错误回退为 HTML |
| 前端性能写入 | 未登录 `POST performance.recordVitals` 返回 `401 AUTH_REQUIRED`，没有写入任何指标 |
| 图片工作流 | 公网页面完成渲染，显示“请选择一个项目”安全空态；未出现前端控制台错误 |
| 服务运行 | 三项服务均 active；Nginx 配置通过校验 |

## 本地工程门禁

- 性能采集、性能路由、观测聚合、请求耗时、优雅停止、错误边界、懒加载恢复、静态缓存等定向回归通过。
- 修改后全量 TypeScript 检查为 **0 诊断**。
- 客户端未定义标识符门禁、ESLint、生产构建及 Bundle 预算通过。

## 已知非阻断项

生产启动日志仍会记录一个历史 Manus OAuth 基址为空的告警。运行环境中该变量存在但为空；本次没有猜测或写入 OAuth 服务地址。该告警不影响当前健康端点、前端页面或本次性能发布；若要接管/修复该历史登录路径，需先确认应使用的 OAuth 提供方地址和登录切换范围。

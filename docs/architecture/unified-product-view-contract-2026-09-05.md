# 统一产品总览与详情数据合同

## 目标

产品总览与产品详情在前台只保留**一套界面和一个路由入口**。领星MCP、ERP上传、日ASIN快照与人工产品主档是同一产品的不同来源，不再以独立页面或重复卡片呈现。系统仍保留每条事实的来源与导入历史，以支撑审计和人工复核。

> 设计原则：**AI与系统负责归集、标识和提示；运营人员负责修改主档和确认异常。** 系统不以不同来源的同一指标重复累计，也不以模糊父子关系推导成员。

## 规范产品身份与单入口流程

| 环节 | 规则 | 前台表现 |
| --- | --- | --- |
| 身份归并 | 以 `parentAsin + storeName + country` 为规范父产品身份；子体以该身份加 `childAsin` 归并。所有字段进行去空格、大小写规范化。 | 同一父ASIN在不同店铺或站点保持独立产品行；同一身份仅出现一次。 |
| 产品集合 | 以MCP父ASIN周事实、ERP导入历史和人工产品主档的身份并集建立产品行。 | 一个“产品总览”页签；不再显示“MCP父ASIN周报 / ERP数据”的双入口。 |
| 周度经营指标 | 当前及未来自然周只读领星MCP父ASIN周报；MCP不存在时显示“周报未覆盖”。历史ERP周表仅作为来源化历史参考。 | 周表标题显示“周度来源：领星MCP父ASIN周报”；历史ERP有数据时以辅助标签说明，不能自动加总。 |
| 单ASIN日指标与库存 | 销量、利润、广告、Session、可售/在途库存来自同身份、同日期的ASIN日快照；库存规划继续使用其既有独立快照逻辑。 | 进入同一“产品详情”后展示子ASIN日指标表，列头标识来源与覆盖日期。 |
| 人工主档 | 负责人、图片、内部中文名、状态与可编辑基础字段仍由人工主档保存；来源行未匹配主档时只允许查看数据。 | 不再产生第二张卡片；数据行展示“待关联主档”，禁用删除、负责人分配和手工同步。 |

## 字段来源优先级与空值语义

| 字段组 | 首选来源 | 回退规则 | 禁止行为 |
| --- | --- | --- | --- |
| 周销量、订单、销售额、利润、Session、广告指标 | MCP父ASIN自然周事实 | 不以ERP同周数值自动填补；标为未覆盖 | MCP与ERP相加；日快照聚合覆盖MCP周报。 |
| 子ASIN销量、利润、广告、库存 | ASIN日快照的规范子体身份 | 数据窗口不完整时显示“未提供/覆盖不足” | 将缺失写成0；跨店铺或跨站点按裸ASIN合并。 |
| 子ASIN数量 | MCP父周事实中明确列出的成员；未提供时回退同身份日快照成员，再回退精确匹配的手工变体 | 必须显示成员来源 | 按标题、SKU片段或其他模糊关系扩展。 |
| 标题、品牌、类目 | MCP事实优先，其次ERP，再次人工主档 | 保留字段来源供审计 | 把不同来源标题视为不同产品行。 |
| 负责人、图片、内部标签、状态 | 人工主档 | 无主档即为空/待关联 | 将来源中的同名字段静默写回人工主档。 |

## 统一前台交互

产品总览顶部仅保留一个“产品总览”标题和“数据覆盖”筛选。每个产品行显示规范店铺/站点、周度来源状态、日指标最新日期、主档关联状态和子ASIN成员来源；点击任意行进入同一路由的产品详情。来源状态可用于筛选与复核，但不会改变为另一套页面。

产品详情包含“经营周报”“子ASIN日指标”“库存规划关联”“广告归因”四个同页区段。经营周报始终遵守MCP权威口径；日指标和库存明示其日快照日期；广告归因缺失时保留“未提供”而不是填充零。人工维护动作始终针对已关联的唯一主档执行。

## 验收条件

| 验收项目 | 合格标准 |
| --- | --- |
| 总览入口 | 页面无“MCP父ASIN周报 / ERP数据”双切换；一个身份只显示一张产品卡片。 |
| 周度口径 | MCP周事实存在时渲染MCP周数据；不与ERP或日快照重复加总。 |
| 成员准确性 | 子ASIN数量与规范成员集合一致，并可说明成员来源。 |
| 详情完整性 | 同一详情展示子ASIN销售、利润、广告、库存字段以及来源/覆盖状态。 |
| 缺失保护 | 所有缺失或覆盖不足字段显示“未提供”，不伪造0。 |
| 数据安全 | 不删除或覆盖历史ERP、MCP、日快照或人工主档；所有修改具备可回滚版本。 |
